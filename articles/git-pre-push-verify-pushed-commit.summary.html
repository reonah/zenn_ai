Actions の検証を git の pre-push に移すなら、commit と環境を隔離する
作業ツリーでなく push する commit を、呼び出し元の環境を外して検証する
  1. 1
    commit を取り出す

    git archive と read-tree で一時 repo を作り、未 commit の差分を混ぜない

  2. 2
    GIT_DIR を外す

    --local-env-vars を unset しないと元の index を書き換える

  3. 3
    && でつなぐ

    || status=$? の左側では set -e が効かず失敗後も進む

  4. 4
    push 元の環境

    rg の無い Mac と定期実行の環境変数でテストが落ちた
